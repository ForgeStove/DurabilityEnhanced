# Durability Enhanced

## 项目简介

> **Durability Enhanced** 是一个仅服务端的模组，旨在优化铁砧修复机制，提升游戏体验。

- **核心功能**：允许玩家在铁砧修复物品时，不再累计修复惩罚（即修复成本不会随着修复次数增加而递增），让装备的使用寿命大幅提升。

> **Durability Enhanced** is a server-side mod for Minecraft that optimizes the anvil repair mechanism, making item repairs no longer accumulate penalties. This greatly extends the lifespan of your equipment and enhances the gameplay experience.

- **Core Feature**: Prevents the anvil from increasing repair costs with each use (no repair penalty accumulation).
